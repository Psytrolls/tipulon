# טיפולון – מערכת דיגיטלית לניהול טיפול מונע באוטובוסים

מערכת מלאה ורספונסיבית (Mobile-First) בעברית מלאה (RTL) לניהול, ביצוע ותיעוד של טיפולים מונעים בציוד המותקן באוטובוסים, בהתאם למסמך האפיון המלא (גרסה 1.0).

---

## 🚀 הוראות הפעלה מהירות

### דרישות קדם
- Node.js גרסה 20 ומעלה (הפרויקט עושה שימוש ב-`node:sqlite` המובנה ב-Node).

### התקנה והרצה
1. התקנת תלויות (אם טרם הותקנו):
```bash
npm install
```

2. הרצת המערכת (שרת + ממשק משתמש):
```bash
npm run dev
```

3. פתיחת הדפדפן בכתובת:
```
http://localhost:3000
```

---

## 🔑 ניהול משתמשי מערכת ואבטחה

המערכת פועלת במדיניות סיסמאות קפדנית (מינימום 12 תווים למנהלים, ללא סיסמאות ברירת מחדל).

### יצירת מנהל על ראשוני (Super Admin)
להגדרת משתמש מנהל ראשוני במערכת, יש להריץ בשרת:
```bash
node server/initSuperAdmin.js <טלפון> "<סיסמה_מאובטחת>" "<שם_מלא>"
```
לדוגמה:
```bash
node server/initSuperAdmin.js 0500000000 "AdminSecurePass#2026" "System Administrator"
```
המערכת תחייב עדכון סיסמה בכניסה הראשונה (`must_change_pin = 1`).

## 🚌 תרחישי בדיקה ושימוש במערכת

### 1. בדיקת חסימת טיפול כפול (חוק עסקי סעיף 5.1 & 8.1)
- התחבר עם חשבון טכנאי פעיל.
- חפש אוטובוס שבוצע לו טיפול מונע תקף בחצי השנה האחרונה.
- המערכת תציג הודעה: **"אין צורך בביצוע טיפול מונע לאוטובוס זה!"** ותחסום ביצוע טיפול כפול.

### 2. ביצוע טיפול מונע מלא
- חפש אוטובוס שדורש טיפול (לפי לוחית רישוי או מספר פנימי).
- בחר כמות מכשירים לבדיקה (בין 3 ל-12).
- מלא את פרטי כל מכשיר: בחר סוג מוצר מתוך הקטלוג הפעיל, הזן מספר סידורי, וסמן תקין/לא תקין.
- הזן סיכום טיפול ובחר: "הכול תקין באוטובוס" או "נדרש המשך טיפול של הלקוח".
- עבור על מסך הסקירה ואשר שמירת דוח סופי.

### 3. תור המשך טיפול ולוח בקרה למנהל
- התחבר עם חשבון מנהל מערכת.
- צפה במוני ה-KPI בזמן אמת: טיפולים היום, נדרש טיפול, המשך טיפול, באיחור, וסגירות EDI.
- פתח את לשונית **תור המשך טיפול** לניהול אוטובוסים עם תקלות פתוחות וסגירתן.
- פתח את **דוחות והיסטוריה** להורדת קובץ Excel (עם קידוד UTF-8 מלא לעברית).
- נהל מוצרים ומשתמשים מהתפריט העליון.

## 🛠️ ארכיטקטורה טכנולוגית

- **Frontend**: React 18, Tailwind CSS (RTL מלא, תמיכה במסכי מובייל ודסקטופ), Lucide Icons, ממשק Mobile-First תואם PWA.
- **Backend**: Express.js REST API מאובטח (עוגיות HttpOnly, Rate Limiting, מניעת Timing Attacks).
- **Database**: מסד נתונים SQLite מתמשך בקובץ מקומי (`data/tipulon.db`) באמצעות מודול `node:sqlite`.
- **גיבויים ואבטחה**: גיבוי אוטומטי לילי מוצפן ב-AES-256-GCM, גיבוב סיסמאות PBKDF2 (220,000 איטרציות), והצפנת טוקני סשן ב-SHA-256.
